# Wecker App

Eine einfache Android-Wecker-App mit Alarm, Snooze und Benachrichtigung.

## Funktionen
- Uhrzeit auswählen und Alarm setzen
- Alarm abbrechen
- Snooze mit einstellbarer Minutenanzahl
- Notification mit neuer Alarmzeit nach Snooze

## Start
1. Projekt in Android Studio öffnen.
2. App auf Emulator oder Gerät starten.
3. Zeit wählen und `Alarm setzen` drücken.
